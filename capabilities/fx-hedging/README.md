# FX Hedging Capability
 
This capability covers hedging a foreign-currency transaction exposure: comparing a forward, a money-market hedge, and an option hedge against no hedge, and testing the result across a range of exchange rates. The specification describes the named-range inputs, calculation flow, tab layout, and validation checks that a workbook must follow.
